# results/paper1_environment/figures

This directory contains the publication-ready figures for Paper 1.

## Files

| File | Description |
|------|-------------|
| `figure_env_final.pdf` | Scatter δF3 vs e_env (N=54), OLS fit + CI95, coloured by log M★ |
| `figure_env_final.png` | Same — raster version for arXiv/submission |
| `figure_robustness_final.pdf` | β_env and p-value vs n_tail threshold sweep |
| `figure_robustness_final.png` | Same — raster version |

## Generation

Figures are generated by `scripts/generate_env_figure.py` from the physical subset CSV.

```bash
python3 scripts/generate_env_figure.py \
    --input results/paper1_environment/data/scm_final_subset_n10.csv \
    --out   results/paper1_environment/figures/
```

> **Note:** Upload `scm_figure_env_n10.{png,pdf}` and
> `scm_robustness_threshold.{png,pdf}` from `SCM_RESULTS_FINAL/` (Drive)
> to this directory (renaming to `figure_env_final.*` and
> `figure_robustness_final.*`) before creating the GitHub release.
