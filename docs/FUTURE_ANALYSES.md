# Future Analyses

This document outlines planned extensions of the SCM framework that are not included in the current paper but represent natural next steps.

## Environment-dependent modulation of outer-disc dynamics

**Objective**  
Test whether the environmental modulation of outer-disc kinematics, quantified through $F_3$, is itself environment-dependent. In practice, this means testing whether the slope of $F_3$ versus $\delta_{\rm mass}$ differs between low-density and high-density environments.

**Methodology**
- Use the SPARC-based outputs already generated by the main pipeline.
- Treat $\delta_{\rm mass}$ as the primary continuous predictor.
- Define an exploratory stratification into `void`, `intermediate`, and `filament` environments using either:
  - percentile-based thresholds (applied as quantiles of $\delta_{\rm mass}$), or
  - fixed thresholds in $\delta_{\rm mass}$ units.
- Compare three nested models:
  - $F_3 \sim \delta_{\rm mass}$
  - $F_3 \sim \delta_{\rm mass} + C(\mathrm{env})$
  - $F_3 \sim \delta_{\rm mass} \times C(\mathrm{env})$

**Statistical tools**
- OLS with HC3 robust standard errors
- AIC and AICc model comparison
- Bootstrap confidence intervals for the interaction coefficient
- Welch-style test for slope differences between void and filament groups
- Sensitivity analysis across threshold definitions

**Status**  
Implemented as an exploratory script in:

```text
scripts/environment_interaction_analysis.py
```

Outputs are written to:

```text
results/environment_interaction/
```

**Why this is not in the current paper**

The current paper is focused on the global evidence for environmental modulation, supported by $\Delta$AIC and OOS validation.

If `env` is defined directly from $\delta_{\rm mass}$, the resulting interaction analysis is not fully independent and should therefore be treated as exploratory rather than confirmatory.

A stronger confirmatory version would require an independent environmental classifier.

**Natural follow-up**

- Use an external large-scale structure catalog to define void/filament membership independently of $\delta_{\rm mass}$.
- Extend the analysis to LITTLE THINGS.
- Compare with simulated samples (e.g. TNG100/TNG300 or EAGLE).
- Evaluate whether the interaction term remains stable across datasets and environmental definitions.

**Paper-compatible summary sentence**

> A natural extension is to test whether the environmental modulation itself depends on large-scale environment (e.g. filaments versus voids), which would further constrain the interpretation of $\delta_{\rm mass}$ as an effective driver of outer-disc dynamics.

**Current status**

The script structure and outputs have been verified end-to-end using a synthetic per-galaxy input table.

> **The interaction-analysis pipeline is operational, but execution on real SPARC galaxies requires an external per-galaxy environmental table containing `galaxy` and `delta_mass`, consistent with the definition adopted in the paper.**

**Column provenance**

| Column | Definition | Source |
|---|---|---|
| `F3` | Deep-regime velocity slope (`friction_slope` / `beta`) | `scripts/generate_f3_catalog.py` → `results/f3_catalog_real.csv` |
| `delta_mass` | Stellar mass overdensity at 3 Mpc: (ρ_local/⟨ρ⟩) − 1 (see `docs/paper1/methods_delta_mass.md`) | **External LSS catalogue** — not produced by any script in this repo |
| `delta_dyn` / `delta_g` | Per-galaxy median of log10(g_obs) − log10(g_bar) | Derivable from SPARC rotmod files — **must not be named `delta_mass`** |

**Generating F3**

```bash
python scripts/generate_f3_catalog.py \
    --data_dir data/SPARC/rotmod \
    --out results/f3_catalog_real.csv
```

**Building `results/environment_interaction/per_galaxy_env_f3.csv`**

Once an external `delta_mass` table is available (minimum columns: `galaxy`, `delta_mass`):

```python
import pandas as pd
from pathlib import Path

Path("results/environment_interaction").mkdir(parents=True, exist_ok=True)

f3  = pd.read_csv("results/f3_catalog_real.csv")[["galaxy", "friction_slope", "reliable"]]
env = pd.read_csv("<external_delta_mass_table>.csv")[["galaxy", "delta_mass"]]

merged = f3.merge(env, on="galaxy", how="inner")
merged = merged.rename(columns={"friction_slope": "F3"})
merged = merged[merged["reliable"] == True].copy()

merged["source_f3"]         = "generate_f3_catalog.py"
merged["source_delta_mass"] = "<external_catalogue_name>"

merged.to_csv("results/environment_interaction/per_galaxy_env_f3.csv", index=False)
```

Then run the analysis:

```bash
python scripts/environment_interaction_analysis.py \
    --input results/environment_interaction/per_galaxy_env_f3.csv
```

**Blocking item**

`delta_mass` (environmental proxy) is **not** computed by any script in this repository and is pending supply from an external large-scale structure catalogue.
`F3` is fully automated and ready to generate once SPARC rotmod files are present.
