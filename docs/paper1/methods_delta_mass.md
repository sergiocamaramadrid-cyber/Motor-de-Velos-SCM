# Definition of the environmental proxy δ_mass

δ_mass is defined as the stellar mass overdensity within a sphere of radius 3 Mpc (comoving) centred on each galaxy:

δ_mass = (ρ_local / ⟨ρ⟩) − 1

where:

- ρ_local = Σ M* / V is the local stellar mass density
- ⟨ρ⟩ is the mean stellar mass density at comparable redshift (consistent with the SPARC sample, z < 0.03)

Neighbouring galaxies are selected from an external catalogue with stellar masses M* > 10^9 M☉ to minimise incompleteness.

The 3 Mpc scale is chosen to probe the large-scale environment (filaments/voids) while reducing contamination from the galaxy’s own halo or group.

For galaxies with no neighbours within 3 Mpc, a lower-limit value (δ_mass ≈ −1) is assigned, consistent with void environments.

This definition is intended as a phenomenological proxy for environment, not a direct measurement of physical pressure.
