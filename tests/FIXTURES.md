# Test Fixtures

## `results/f3_catalog_synthetic_flat.csv`

This file is a **synthetic test fixture** — it is **not** a scientific result.

It contains artificially generated galaxy data with known properties (flat rotation
curves, planted MOND-compliant slopes) used by the CI test suite to verify that the
f3 catalog and deep-slope analysis pipelines produce correct output without requiring
real SPARC data.

| Property | Value |
|---|---|
| Used by | `tests/test_f3_catalog.py`, `tests/test_f3_catalog_analysis.py` |
| Generated by | Synthetic data builder in the respective test modules |
| Scientific content | None — values are not observational measurements |

It lives in `results/` because the pipeline scripts write their output there, and
the tests check for output at that path. It is committed so the test suite can run
offline in CI without downloading real data.
