This notice serves as a formal public disclosure of the SCM (Motor de Velos /
Fluid Condensation Model) framework, its associated source code, data pipelines,
and analysis methodology.

SCOPE OF DISCLOSURE
-------------------
This disclosure covers:
- The conceptual model known as Motor de Velos (SCM), as described in the
  repository documentation and the Zenodo archive referenced above.
- All source code, scripts, and notebooks contained in this repository as of
  the version indicated above.
- All data contracts, statistical protocols, and reproducible evaluation
  pipelines published in this repository.

PRIORITY AND ORIGINALITY
-------------------------
The SCM framework was first consolidated by the author on 2026-02-12. This
public disclosure, together with the Zenodo DOI record, constitutes an
independent, timestamped record of the work for priority purposes.
