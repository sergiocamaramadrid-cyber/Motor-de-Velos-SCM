## Data attribution

The analyses use the following external datasets, which must be cited
independently:

- **SPARC**: Lelli, F., McGaugh, S. S., & Schombert, J. M. (2016).
  *SPARC: Mass Models for 175 Disk Galaxies with Spitzer Photometry and
  Accurate Rotation Curves.* AJ, 152, 157.
  https://doi.org/10.3847/0004-6256/152/6/157

- **LITTLE THINGS**: Hunter, D. A., et al. (2012).
  *LITTLE THINGS.* AJ, 144, 134.
  https://doi.org/10.1088/0004-6256/144/5/134

- **Chae environment proxy**: Chae, K.-H. (2022).
  Environmental parameter table used in the OLS environmental analysis.

## Notes

Once the Zenodo deposit has been created and a DOI has been assigned, replace
`10.5281/zenodo.XXXXXXX` in this file and in `CITATION.cff` with the actual DOI.
The Zenodo badge in `README.md` should also be updated accordingly.
